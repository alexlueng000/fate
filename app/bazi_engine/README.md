# Bazi Engine

确定性的八字计算与规则推导层。

本目录负责历法、命盘标准化、十神与藏干、干支关系、旺衰、喜用及流运计算。核心模块应保持为无数据库、无 HTTP、无大模型依赖的纯函数，所有公开结果必须带计算版本并可通过金标案例回归。

规划模块：

- `schemas.py`：统一命盘输入、输出及计算配置。
- `versions.py`：计算版本及兼容策略。
- `calendar.py`：时区、节气、真太阳时与换日规则。
- `chart.py`：四柱、大运及标准命盘构建。
- `hidden_stems.py`：藏干计算。
- `ten_gods.py`：十神计算。
- `relations.py`：合、冲、刑、害、破等关系。
- `strength.py`：旺衰候选与证据。
- `useful_elements.py`：喜用忌候选与推导依据。
- `transit.py`：大运、流年和流月作用关系。
- `validators.py`：命盘和推导结果一致性检查。

初期不要修改现有 `app/routers/bazi.py` 的生产返回结果。新引擎完成金标验证后，先以影子模式对比，再通过版本开关灰度接入。
